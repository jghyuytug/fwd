## ⚡ 快速启动（3步）

### 步骤1: 编译后端（仅首次）

在Docker环境中编译：
```bash
docker run -v "C:\Users\waw\Desktop\game":/build dnf_game_builder bash -c "
    yum install -y zlib-devel.i686 >/dev/null 2>&1 &&
    cd /build/tools/pvf_browser/backend &&
    make
"
```

或在本地编译（如果有环境）：
```bash
cd backend
make
```

✅ 成功标志：生成 `backend/pvf_api` 文件

### 步骤2: 启动服务器

**Windows**:
```cmd
start.bat
```

**Linux/macOS**:
```bash
chmod +x start.sh
./start.sh
```

✅ 成功标志：看到"服务器已启动" + URL地址

### 步骤3: 打开浏览器

访问: **http://localhost:8000**

✅ 成功标志：看到装备浏览器界面

## 🔧 常见问题

### Q1: 编译失败 - "cannot find -lz"
**A**: 安装32位zlib库
```bash
# Ubuntu/Debian
sudo apt-get install zlib1g-dev:i386

# CentOS/RHEL (Docker)
yum install zlib-devel.i686
```

### Q2: 服务器启动失败
**A**: 检查是否已编译后端
```bash
ls -l backend/pvf_api     # 应该存在
```

### Q3: 无法加载装备
**A**: 检查PVF路径
```python
# 编辑 server.py
PVF_PATH = "../../Script.pvf"  # 修改为正确路径
```

### Q4: 端口8000被占用
**A**: 修改端口号
```python
# 编辑 server.py
PORT = 8080  # 改为其他端口
```

### Q5: 浏览器无法连接
**A**: 检查服务器是否正在运行
```bash
# 应该看到类似输出:
# 服务器地址: http://localhost:8000
# 按 Ctrl+C 停止服务器
```

./backend/pvf_api search ../../Script.pvf belt all
